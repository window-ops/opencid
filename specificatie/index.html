OpenCID (specificație)

Duceți-vă înapoi ←

Pentru a obține OpenCID-ul asiguratului, se execută următorii pași:

  • Pas 1: Se preia codul numeric personal (CNP) al asiguratului.
  • Pas 2: Fiecare cifră din CNP este înmulțită cu 47.
  • Pas 3: Rezultatele înmulțirilor sunt adăugate la un șir de cifre numit OpenCID.
    • Pas 4.1: Dacă lungimea lui OpenCID este mai mică decât 20 de cifre, se completează șirul cu el însuși până când are 20 de cifre.
    • Pas 4.2: Dacă lungimea lui OpenCID este mai mare de 20 de cifre, se elimină cifrele excedentare.
    • Pas 5.1: Dacă CNP-ul introdus este valid, se returnează OpenCID.
    • Pas 5.2: Dacă CNP-ul introdus nu are 13 cifre sau nu este un număr, se returnează un mesaj de eroare.

Aceasta este o implementare a specificației în Javascript:

function obtineopenciddincnp(cnp) {
  var openCID = '';
  var nrCifre = 20;

  // Verifică dacă CNP-ul introdus are 13 cifre
  if (cnp.length === 13 && !isNaN(cnp)) {
    // Parcurge fiecare cifră din CNP
    for (var i = 0; i < cnp.length; i++) {
      // Converteste cifra din CNP la număr și înmulțește cu 47
      var cifraInmultita = parseInt(cnp[i]) * 47;
      // Adaugă cifrele rezultate la OpenCID
      openCID += cifraInmultita;
    }

    // Repetă primele cifre până când sunt [nrCifre] de cifre dacă sunt mai puțin de [nrCifre] de cifre
    while (openCID.length < nrCifre) {
      openCID += openCID;
    }

    // Elimină ultimele cifre până se ajunge la [nrCifre] de cifre dacă sunt peste [nrCifre] de cifre
    openCID = openCID.slice(0, nrCifre);

    // Returnează OpenCID-ul obținut
    return openCID;
  } else {
    // Returnează un mesaj de eroare dacă CNP-ul introdus nu are 13 cifre sau nu este un număr
    return 'CNPInvalid';
  }
}
